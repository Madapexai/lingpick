## 🎯 Was ist LingPick?

LingPick ist eine **KI-gestützte Plattform zur Werkzeugentdeckung**, die dir hilft, die besten KI-Werkzeuge zu den niedrigsten Kosten zu finden. Wir haben **über 14.000 KI-Werkzeuge** und **über 400 KI-Modelle** indexiert — du musst nicht mehr selbst alles vergleichen.

> **Problem:** 50 Browser-Tabs, 3 Vergleichstabellen, 2 Stunden Arbeit — nur um einen Videogenerator für unter 30 $/Monat zu finden.

> **Lösung:** Sag uns, was du tun möchtest. In 30 Sekunden erhältst du 3 nach Kosten sortierte Empfehlungen.

```
Du: "Ein Produktvorstellungsvideo erstellen"
LingPick: → Video Podcast Maker (Kostenlos)
          → Hailuo AI Video (4,99 $/Monat)
          → CogVideoX 2.0 (Open Source)
```

## ✨ Funktionen

| Funktion | Beschreibung |
|------|------|
| 🔍 **Intelligente Suche** | Mehrsprachige semantische Suche (CN/EN/JP), über 14.000 Werkzeuge abgedeckt |
| ⚡ **Schnelles Matching** | 5 Fragen beantworten → 3 präzise Empfehlungen, sortiert nach Kosten, Relevanz und Geschwindigkeit |
| 📖 **Vollständiger Katalog** | Nach Kategorie durchsuchen: Video, Bild, Programmierung, Schreiben, Musik, Agent, CLI, MCP |
| 💸 **Modell-Preisvergleich** | Preisvergleich von über 400 KI-Modellen (GPT-4, Claude, Gemini, Llama, DeepSeek u.v.m.) |
| 🎯 **Szenario-Lösungen** | Echte Workflows aus Reddit, Zhihu, Hacker News, mit Kostenanalyse |
| 🤖 **LingBot-Assistent** | KI-gestützte dialogbasierte Werkzeugempfehlung, ausgelöst durch 25 Schlüsselwörter |
| 🌏 **12 Sprachen** | English / 中文 / Français / 日本語 / 한국어 / Tiếng Việt / Deutsch / Русский / العربية / हिन्दी / Indonesia / 繁體中文 |
| 🔄 **Echtzeit-Daten** | Stille Aktualisierung alle 10 Minuten, dreistufiger Cache |

## 🚀 Schnellstart

1. Öffne **[madapexai.com](https://madapexai.com)**
2. Gib in das Suchfeld ein, was du tun möchtest
3. Erhalte sofort Ergebnisse

### Suchbeispiele

| Du gibst ein | LingPick findet |
|--------|-------------|
| "做视频" | KI-Videowerkzeuge, AIGC-Videoerstellung, CogVideoX |
| "写代码" | 天工智码 Skycode, 码上飞, Kimi K3 for Coding |
| "做PPT" | Dashi PPT, McKinsey PPT Design |
| "AI绘画" | 创客贴 AI 画匠, 秒绘 AI, 绘蛙 AI |
| "数据分析" | Datenanalyse-Werkzeugsammlung |
| "make video" | Video Podcast Maker, Hailuo AI Video |
| "coding" | cli-llm-coding, Live Coding in Forth |

### LingBot-Auslösewörter

Gib eines der folgenden Schlüsselwörter ein, um den KI-Assistenten automatisch zu aktivieren:
`客服` `人工客服` `help` `support` `联系客服` `售后` `技术支持` `帮助` `求助` `反馈` `投诉` `complaint`

## 🏗️ Architektur

| Schicht | Technologie-Stack |
|------|--------|
| **Frontend** | React 18, Vite, TypeScript, i18next, Tailwind CSS |
| **Suche** | Fuse.js (hybride Keyword- + Vektorsuche, Schwellwert 0.35, Markengewichtung) |
| **Backend** | Node.js, Express, PostgreSQL, PM2 |
| **Cache** | Dreistufiger Cache (HOT 5 Min. / WARM 1 Std. / COLD 24 Std.) + stille Hintergrundaktualisierung |
| **CI/CD** | GitHub Actions → Vercel (Frontend) + Contabo PM2 (Backend) |
| **Internationalisierung** | 12-sprachige Übersetzungsdateien, en-US-Fallback, dynamisches html[lang] |
