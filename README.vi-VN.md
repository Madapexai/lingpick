## 🎯 LingPick là gì?

LingPick là một **nền tảng khám phá công cụ AI** giúp bạn tìm công cụ AI phù hợp nhất với chi phí thấp nhất. Chúng tôi đã lập chỉ mục **hơn 14.000 công cụ AI** và **hơn 400 mô hình AI** — không cần phải tự so sánh từng cái một nữa.

> **Vấn đề:** Mở 50 tab trình duyệt, tạo 3 bảng so sánh, mất 2 giờ — chỉ để tìm một công cụ tạo video dưới $30/tháng.

> **Giải pháp:** Cho chúng tôi biết bạn muốn làm gì, nhận 3 đề xuất được sắp xếp theo chi phí trong 30 giây.

```
Bạn: "Tạo video giới thiệu sản phẩm"
LingPick: → Video Podcast Maker (Miễn phí)
          → Hailuo AI Video ($4.99/tháng)
          → CogVideoX 2.0 (Mã nguồn mở)
```

## 🏗️ Kiến trúc

| Tầng | Công nghệ |
|------|--------|
| **Frontend** | React 18, Vite, TypeScript, i18next, Tailwind CSS |
| **Tìm kiếm** | Fuse.js (tìm kiếm lai từ khóa + vector, ngưỡng 0.35, trọng số thương hiệu) |
| **Backend** | Node.js, Express, PostgreSQL, PM2 |
| **Bộ nhớ đệm** | Bộ đệm ba cấp (HOT 5 phút / WARM 1 giờ / COLD 24 giờ) + làm mới ngầm nền |
| **CI/CD** | GitHub Actions → Vercel (Frontend) + Contabo PM2 (Backend) |
| **Quốc tế hóa** | Tệp dịch 12 ngôn ngữ, dự phòng en-US, html[lang] động |
