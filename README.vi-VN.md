## 🏗️ Kiến trúc

```
┌─────────────────────────────────────────────┐
│                  Vercel CDN                   │
│           (React + Vite SPA)                  │
├─────────────────────────────────────────────┤
│  i18next (12 ngôn ngữ)  │  Fuse.js Kết hợp  │
├─────────────────────────────────────────────┤
│              Cổng API REST                    │
│          (Express + PostgreSQL)                │
├──────────┬──────────┬──────────┬─────────────┤
│ Tìm kiếm  │ Danh mục  │ Thống kê  │  LingBot    │
│  /agent   │  /models  │  /stats  │  /chat      │
├──────────┴──────────┴──────────┴─────────────┤
│      Bộ nhớ đệm 3 cấp (HOT/WARM/COLD)      │
│      Làm mới nền (chu kỳ 10 phút)           │
└─────────────────────────────────────────────┘
```

| Lớp | Công nghệ |
|-----|-----------|
| **Frontend** | React 18, Vite, TypeScript, i18next, Tailwind CSS |
| **Tìm kiếm** | Fuse.js (kết hợp từ khóa + vector, ngưỡng 0.35, tăng cường thương hiệu) |
| **Backend** | Node.js, Express, PostgreSQL, PM2 |
| **Bộ nhớ đệm** | HOT (5 phút) / WARM (1 giờ) / COLD (24 giờ), làm mới nền |
| **CI/CD** | GitHub Actions → Vercel (frontend) + Contabo PM2 (backend) |
| **I18n** | 12 tệp dịch, dự phòng en-US, html[lang] động |
