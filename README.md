## 🏗️ Under the Hood

```
┌───────────────────────────────────────────────────────┐
│                    🌐 Vercel CDN                       │
│               (React 18 + Vite SPA)                    │
│                                                       │
│  i18next (12 languages)   │   Fuse.js Hybrid Search   │
├───────────────────────────────────────────────────────┤
│                  🔌 REST API Gateway                   │
│              (Express + PostgreSQL)                    │
│                                                       │
│  /agent (Search)  │  /models  │  /stats  │  /chat     │
├───────────────────────────────────────────────────────┤
│         🗄️ 3-Tier Cache (HOT / WARM / COLD)           │
│         🔄 Silent Background Refresh (10 min)          │
└───────────────────────────────────────────────────────┘
```

| Layer | Technology |
|-------|-----------|
| **Frontend** | React 18, Vite, TypeScript, i18next, Tailwind CSS |
| **Search Engine** | Fuse.js — keyword + vector hybrid, threshold 0.35, brand-aware boosting |
| **Backend** | Node.js, Express, PostgreSQL, PM2 process manager |
| **Caching** | 3-tier: HOT (5 min) / WARM (1 hour) / COLD (24 hours), silent refresh |
| **CI/CD** | GitHub Actions → Vercel (frontend) + Contabo VPS (backend) |
| **Internationalization** | 12 translation files, en-US fallback, dynamic `html[lang]` switching |
