## 🎯 LingPick とは？

LingPick は、**AI 駆動のツール発見プラットフォーム**です。最小のコストで最適な AI ツールを見つけるお手伝いをします。**14,000 以上の AI ツール**と**400 以上の AI モデル**をインデックス化しており、一つ一つ比較する手間はもう必要ありません。

> **課題：** 50 個のブラウザタブ、3 つの比較表、2 時間の作業 — 月額 $30 未満の動画生成ツールを探すだけのために。

> **解決策：** やりたいことを教えてください。30 秒でコスト順に 3 つのおすすめを表示します。

```
あなた：「製品紹介動画を作りたい」
LingPick：→ Video Podcast Maker (無料)
           → Hailuo AI Video ($4.99/月)
           → CogVideoX 2.0 (オープンソース)
```

## ✨ 機能

| 機能 | 説明 |
|------|------|
| 🔍 **スマート検索** | 中国語・英語・日本語のマルチ言語セマンティック検索、14,000 以上のツールをカバー |
| ⚡ **高速マッチング** | 5 つの質問に答える → コスト、適合度、速度でソートされた 3 つの精密なおすすめ |
| 📖 **完全カタログ** | カテゴリ別ブラウズ：動画、画像、プログラミング、文章作成、音楽、Agent、CLI、MCP |
| 💸 **モデル価格比較** | 400 以上の AI モデルの価格を横断比較（GPT-4、Claude、Gemini、Llama、DeepSeek など） |
| 🎯 **シナリオソリューション** | Reddit、知乎、Hacker News から抽出した実践的なワークフロー、コスト分析付き |
| 🤖 **LingBot アシスタント** | AI 会話型ツール推薦、25 のキーワードで自動起動 |
| 🌏 **12 言語対応** | English / 中文 / Français / 日本語 / 한국어 / Tiếng Việt / Deutsch / Русский / العربية / हिन्दी / Indonesia / 繁體中文 |
| 🔄 **リアルタイムデータ** | 10 分ごとのバックエンドサイレントリフレッシュ、3 層キャッシュ |

## 🏗️ アーキテクチャ

| レイヤー | 技術スタック |
|------|--------|
| **フロントエンド** | React 18、Vite、TypeScript、i18next、Tailwind CSS |
| **検索** | Fuse.js（キーワード + ベクトルハイブリッド検索、閾値 0.35、ブランド重み付け） |
| **バックエンド** | Node.js、Express、PostgreSQL、PM2 |
| **キャッシュ** | 3 層キャッシュ（HOT 5 分 / WARM 1 時間 / COLD 24 時間）+ バックグラウンドサイレントリフレッシュ |
| **CI/CD** | GitHub Actions → Vercel（フロントエンド）+ Contabo PM2（バックエンド） |
| **国際化** | 12 言語の翻訳ファイル、en-US フォールバック、動的 html[lang] |
