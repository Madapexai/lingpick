## 🎯 Что такое LingPick?

LingPick — это **платформа для поиска ИИ-инструментов на базе ИИ**, которая помогает найти лучшие инструменты с минимальными затратами. Мы проиндексировали **более 14 000 ИИ-инструментов** и **более 400 ИИ-моделей** — вам больше не нужно сравнивать всё самостоятельно.

> **Проблема:** 50 вкладок в браузере, 3 сравнительные таблицы, 2 часа времени — только чтобы найти видеогенератор дешевле $30/мес.

> **Решение:** Расскажите, что вы хотите сделать. Получите 3 рекомендации, отсортированные по стоимости, за 30 секунд.

```
Вы: "Создать презентационное видео о продукте"
LingPick: → Video Podcast Maker (Бесплатно)
          → Hailuo AI Video ($4.99/мес)
          → CogVideoX 2.0 (Открытый исходный код)
```

## 🚀 Быстрый старт

1. Откройте **[madapexai.com](https://madapexai.com)**
2. Введите в поисковую строку, что вы хотите сделать
3. Мгновенно получите результаты

### Примеры поиска

| Вы вводите | LingPick находит |

| "做视频" | ИИ-инструменты для видео, AIGC-видео, CogVideoX |

`客服` `人工客服` `help` `support` `联系客服` `售后` `技术支持` `帮助` `求助` `反馈` `投诉` `complaint`

## 🏗️ Архитектура

| Уровень | Технологический стек |
|------|--------|
| **Фронтенд** | React 18, Vite, TypeScript, i18next, Tailwind CSS |
| **Поиск** | Fuse.js (гибридный поиск: ключевые слова + векторы, порог 0.35, весовые коэффициенты брендов) |
| **Бэкенд** | Node.js, Express, PostgreSQL, PM2 |
| **Кэш** | Трёхуровневый кэш (HOT 5 мин / WARM 1 ч / COLD 24 ч) + фоновое тихое обновление |
| **CI/CD** | GitHub Actions → Vercel (фронтенд) + Contabo PM2 (бэкенд) |
| **Интернационализация** | Файлы перевода на 12 языков, fallback en-US, динамический html[lang] |
