## 🎯 Qu'est-ce que LingPick ?

LingPick est une **plateforme de découverte d'outils IA** qui vous aide à trouver les meilleurs outils IA au coût le plus bas. Nous indexons **plus de 14 000 outils IA** et **plus de 400 modèles IA** — plus besoin de tout comparer vous-même.

> **Problème :** 50 onglets ouverts, 3 tableaux comparatifs, 2 heures perdues — juste pour trouver un générateur vidéo à moins de 30 $/mois.

> **Solution :** Dites-nous ce que vous voulez faire, obtenez 3 recommandations classées par coût en 30 secondes.

```
Vous : "Créer une vidéo de présentation produit"
LingPick : → Video Podcast Maker (Gratuit)
            → Hailuo AI Video (4,99 $/mois)
            → CogVideoX 2.0 (Open Source)
```

## ✨ Fonctionnalités

| Fonctionnalité | Description |
|------|------|
| 🔍 **Recherche intelligente** | Recherche sémantique multilingue (CN/EN/JP), couvrant plus de 14 000 outils |
| ⚡ **Matching rapide** | 5 questions → 3 recommandations précises, classées par coût, pertinence et rapidité |
| 📖 **Catalogue complet** | Navigation par catégorie : Vidéo, Image, Programmation, Rédaction, Musique, Agent, CLI, MCP |
| 💸 **Comparaison de modèles** | Comparaison des prix de plus de 400 modèles IA (GPT-4, Claude, Gemini, Llama, DeepSeek, etc.) |
| 🎯 **Scénarios pratiques** | Workflows réels extraits de Reddit, Zhihu, Hacker News, avec analyse des coûts |
| 🤖 **Assistant LingBot** | Recommandation d'outils par IA conversationnelle, déclenchée par 25 mots-clés |
| 🌏 **12 langues** | English / 中文 / Français / 日本語 / 한국어 / Tiếng Việt / Deutsch / Русский / العربية / हिन्दी / Indonesia / 繁體中文 |
| 🔄 **Données en temps réel** | Rafraîchissement silencieux toutes les 10 minutes, cache à trois niveaux |

## 🏗️ Architecture

| Couche | Stack technique |
|------|--------|
| **Frontend** | React 18, Vite, TypeScript, i18next, Tailwind CSS |
| **Recherche** | Fuse.js (recherche hybride mots-clés + vectorielle, seuil 0.35, pondération par marque) |
| **Backend** | Node.js, Express, PostgreSQL, PM2 |
| **Cache** | Cache à trois niveaux (HOT 5 min / WARM 1 h / COLD 24 h) + rafraîchissement silencieux |
| **CI/CD** | GitHub Actions → Vercel (Frontend) + Contabo PM2 (Backend) |
| **Internationalisation** | Fichiers de traduction en 12 langues, fallback en-US, html[lang] dynamique |
